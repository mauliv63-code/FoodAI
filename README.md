# FoodAI — Intelligent Food Ordering System

A Python-based console Food Ordering System with an AI-powered recommendation engine, natural-language food preferences, menu browsing, cart management, order processing, and exception handling.

## Project Overview

This project is a console-based food ordering application developed using Python.

The idea was to create a small food-ordering system where users can browse a large menu, search for food, receive personalized AI recommendations, add items to a cart, and place orders.

Unlike a basic food-ordering program, FoodAI includes an **AI recommendation system** that can understand natural-language preferences such as:

→ “I want spicy vegetarian food under ₹250”
→ “I want something filling”
→ “I want a sweet dessert”
→ “Give me a healthy light meal”
→ “I want chicken biryani”

The recommendation engine analyzes these preferences and ranks available food items according to their relevance.

The project also includes a **local AI fallback**, so recommendations can still work when the external AI service is unavailable.

## AI Recommendation System

One of the main parts of this project is the `AIRecommendationEngine`.

The system first converts the user's natural-language request into food preferences.

For example:

```text
User:
I want spicy vegetarian food under ₹250
```

The system identifies preferences such as:

```text
Vegetarian → Yes
Spicy → Yes
Budget → ₹250
```

It then evaluates the available food items and calculates a relevance score.

The recommendation process considers factors such as:

→ Dietary preference
→ Spice preference
→ Food category
→ Budget
→ Rating
→ Health preferences
→ Filling/light preference
→ Sweet preference
→ Protein preference
→ Stock availability
→ Previous recommendations
→ Previous orders

The highest-scoring suitable foods are then presented to the user.

The system also introduces controlled variety between recommendations instead of simply returning the same items every time.

## AI Integration

FoodAI supports an optional external AI integration using the **Anthropic Python SDK**.

When the required API configuration is available, the application can use an Anthropic Claude model to interpret natural-language food preferences.

If the external AI service is unavailable, the program automatically uses its built-in **local rule-based AI system**.

This makes the application more reliable because the recommendation feature does not completely depend on an external API.

The API key is read from an environment variable:

```text
ANTHROPIC_API_KEY
```

Private API keys should never be uploaded to GitHub.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mauliv63-code/FoodAI.git
```

### 2. Open the project folder

```bash
cd FoodAI
```

### 3. Install the optional AI dependency

```bash
pip install anthropic
```

```bash
python foodai.py
```

The application provides a menu-driven console interface where you can browse food, search for items, receive AI recommendations, manage your cart, and place orders.
